# 战纪宇宙原生运营后台

## 定位

`/admin` 是战纪宇宙自研运营后台，由 Next.js 管理界面和 `/_wcu-api/admin/*` 业务 API 组成。JeecgBoot 只保留在 `vendor/jeecg-boot` 作为交互、RBAC 和信息架构参考，不参与本地或宝塔运行。

## 业务域

- 官网运营：品牌与首页、作品、服务、世界观、生产线、团队与顾问。
- 创作生态：项目类型、Skill 工作台、灵穹知识库入口。
- 模型与商业：模型通道、API 调用、充值、支付、账务和登录配置。
- 平台治理：用户与项目、邀请码、管理员、权限和审计日志。

## 认证与隔离

- 后台只使用 `wcu_admin` 管理会话，不覆盖或清理前台的 `wcu_platform_session`。
- 前台创作者不能使用普通账号进入后台；管理员也不复用 New API 的系统管理员账号。
- 管理员登录按 IP、账号和 IP+账号三类散列键持久化节流；连续失败会渐进退避并临时锁定。
- 宝塔反代链由内层网关提取最后一个可信转发地址并写入内部专用请求头，避免所有公网用户共享 Docker 网关 IP。
- 密码校验使用受并发队列保护的异步 scrypt；未知或停用账号也执行同等成本校验，避免账号枚举和高并发 CPU 消耗。
- 部署验收如需内部服务身份，使用独立 `WCU_INTERNAL_SERVICE_SECRET` 和 `X-WCU-Internal-Service-Secret`，仅注入 Platform API，不进入公网 Web 容器。

## 部署

Nginx 将 `/admin` 交给官网 Web 容器，将 `/_wcu-api/admin/*` 交给 Platform API 容器。Compose 不启动 Jeecg 管理端、Spring 服务、Redis 或初始化容器。部署前后均必须通过原生后台登录、身份读取、安全退出与前后台数据联动验收；公网首页、统一登录和原生后台任一验证失败都会触发自动回滚。
