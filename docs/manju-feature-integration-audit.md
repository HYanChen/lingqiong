# 漫剧演示站功能融合审计

审计日期：2026-07-12  
审计范围：用户提供的演示前台、平台后台，以及当前灵穹官网与创作平台。  
原则：只参考功能和生产流程，保留灵穹现有电影感视觉；不复制参考站代码、品牌或数据。

## 1. 验证边界

本轮已使用用户提供的测试账号完成前台和后台登录，并对主要页面、导航、表单、弹窗和只读数据链路逐项检查。

- 已验证：登录、页面可达性、模块入口、列表/筛选、表单字段、项目生产链路、后台配置覆盖范围。
- 未在演示环境执行：创建/删除真实数据、付费生成、充值、支付、卡密兑换、数据库迁移、清缓存、第三方脚本保存。
- 原因：演示后台明确标注不要修改数据；上述动作会产生费用、数据或系统副作用。
- 这些写操作将在灵穹本地隔离测试数据中执行完整的 create → read → update → delete 回归。

## 2. 参考站架构结论

参考站前台与后台共享同一 Next.js 构建制品、同一页面清单和同源 `/api/*` 接口。它是 Next 全栈应用，并非物理前后端分离。

灵穹不照搬该拓扑。目标边界为：

```text
公开官网 / 创作平台  -> 独立 web 运行时
运营管理后台         -> 独立 admin 前端
业务与管理 API       -> 独立 platform-api
模型网关              -> New API
生成任务执行          -> 灵穹 API / 模型执行器
知识沉淀              -> 站内知识工作台（BookStack 仅保留历史入口）
```

前端不得持有数据库账号，也不得直接导入数据库、文件系统、模型密钥或服务端 repository。

## 5. 基线问题与本轮处理结果

### 已完成的底座修复

1. `web` 与 `platform-api` 已分离，数据库凭据只由 API 运行时持有。
2. 管理员 RBAC、接口权限和审计链路已接入，并通过 12 / 12 项角色边界回归。
3. OIDC 使用精确回调白名单；本地浏览器来源统一为 `http://localhost`，`127.0.0.1` 由网关 308 规范化跳转。
4. BookStack 的应用地址、静态资源来源和 OIDC issuer 已统一，浏览器实测排版恢复且统一登录不再返回 `invalid_request` 或 `An unknown error occurred`。
5. 项目中心已迁移到 `/projects`；ComfyUI 的用户入口、反向代理、前端依赖与安装/运行脚本均已移除。
6. 项目导出改为服务端按项目归属汇总并脱敏，项目创建、详情、导出、删除均完成真实浏览器回归。

### 仍需继续建设的边界

1. 参考站的付费图片/视频/配音供应商、积分计费和第三方生成引擎没有照搬；灵穹仍以自身 API 网关与已配置执行器为准。
2. 未配置实际模型或执行器时，生成任务只能保持明确的排队、失败或未配置状态，不能视为已经具备参考站全部生成能力。
3. 团队、订单、支付、卡密和 OEM 多租户属于后续商业化范围，需要在沙盒、回调幂等和财务审计完成后启用。
4. 正式宝塔环境仍需使用正式域名、TLS、数据库和模型授权重跑同一套验收；本地通过不等于远程已经上线。

## 6. 融合实施顺序

1. **运行时分离与安全底座**：独立 platform-api、公共内容 API、管理员 RBAC、Skill/OIDC/上传安全、版本化迁移。
2. **账号与项目底座**：邮箱/手机号账号、项目 CRUD、素材 CRUD、项目风格、提示词模板。
3. **生产实体**：剧集、元素、分镜、配音、合成、导出及异步任务模型。
4. **运营后台**：用户、项目、模型、用量、日志、风格、注册与客服；高风险设置加入权限和审计。
5. **商业与多租户**：积分、订单、支付、卡密、团队、OEM。支付仅在沙盒和回调幂等验证完成后启用。
6. **端到端验收**：游客 → 注册 → 登录 → 项目 → 素材 → 剧本 → 元素 → 分镜 → 配音 → 合成 → 导出 → 后台审计。

## 7. 完成标准

- 所有可见按钮都有真实接口或明确的禁用/未配置状态，不保留假生成和假历史。
- 每个 CRUD 都有创建、读取、修改、删除、越权和异常回滚测试。
- AI 任务都有 queued/running/succeeded/failed/cancelled 状态、超时、重试和费用记录。
- web/admin 构建产物没有数据库凭据，数据库只允许 platform-api 访问。
- API 契约有版本、统一错误结构、输入校验、权限、审计和并发控制。
- MySQL、New API、BookStack 任一服务离线时，公开官网仍可展示，相关模块明确降级。
