# 灵穹官网 JeecgBoot 后台重构

## 目标架构

- `https://pla.wiki/`：继续由 Next.js 提供官网、创作端、用户中心和统一登录。
- `https://pla.wiki/admin/`：由 JeecgBoot Vue3 管理端提供后台界面。
- `https://pla.wiki/jeecgboot/`：由 JeecgBoot Spring Boot 单体服务提供后台 API。
- `jeecg_boot` 数据库：只保存 JeecgBoot 管理员、角色、菜单、字典和审计配置。
- `zhanji_universe` 数据库：继续保存官网用户、项目、生产流程、知识库和模型调用业务数据。
- JeecgBoot 通过只命名为 `lingqiong` 的第二数据源访问业务库，避免初始化脚本覆盖现有数据。

## 已完成接入

1. 运营总览：前台用户、项目、剧集、资产、分镜、排队/失败任务和模型调用统计。
2. 项目管理：项目列表、所有者、类型、比例、目标和风格编辑。
3. 用户管理：账号来源、联系方式、最后登录、启用/停用和资料编辑；不向后台接口暴露密码哈希或盐。
4. 生产任务：任务列表、状态筛选、失败任务重试、排队/执行任务取消。
5. 权限体系：菜单、查看、编辑和任务操作均接入 JeecgBoot RBAC，默认只授权管理员角色。
6. 宝塔编排：新增 JeecgBoot 数据库初始化、Redis、Spring Boot 后台、Vue 管理端和 Nginx 路由。
7. 官网与平台配置：团队顾问增删改、自由新增分组、人物图片直传、微信开放平台、模型接口与项目类型管理。
8. 全业务数据中心：剧集、角色资产、分镜、配音、合成、素材、生成任务、用户、灵穹 API 映射、账单、Skill、知识库、多维表格、附件、评论、版本、自动化与系统审计统一查看和授权编辑。
9. 服务鉴权：JeecgBoot 通过独立内部密钥调用 Next.js 业务 API，不复用管理员会话和前台用户身份。
10. 前后台切换：公网 `/admin/` 只进入 JeecgBoot，旧 Next.js 管理页不再暴露为前台入口；官网、创作端和用户中心继续保持独立运行。

## 上线门槛

- 生成独立 `JEECG_SIGNATURE_SECRET`，不得复用现有会话密钥。
- 初始化后立即修改 JeecgBoot 默认管理员密码，并关闭或删除演示账号和演示菜单。
- 备份 `zhanji_universe`、New API、BookStack 和站点媒体目录。
- 验证 `/admin/` 登录、运营总览、项目编辑、用户停用、任务重试与审计记录。
- 验证官网、创作端、统一登录、New API、知识库和充值页面不受路由切换影响。
